# Koalair

Pilotage des clims Hisense (module Wi-Fi AEH-W4G2) via le cloud ConnectLife, sans l'appli ConnectLife.

Version de test : connexion au compte ConnectLife, affichage des appareils et de leurs valeurs, bouton marche/arrêt.

L'APK est compilé automatiquement à chaque envoi sur `main` et publié dans **Releases**.
